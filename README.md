# Вариант 23. Аудит пользовательских настроек

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Registry, HKCU, права, schema version, IDisposable

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Создать пользовательскую ветку настроек приложения.
2. Считать и вывести все известные значения.
3. Отличать отсутствие ключа от отсутствия отдельного значения.
4. Задать значения по умолчанию.
5. Добавить версию схемы и проверку совместимости.
6. Реализовать сброс только своей ветки.
7. Обрабатывать ошибки доступа и неверные типы значений.

## Дополнительные задания
8. Добавить резервное копирование настроек в JSON.
9. Добавить LastRunUtc.
10. Реализовать миграцию старой схемы.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
